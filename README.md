# sadyr_studio_website

Разработка сайта маркетингового агентства с использованием JavaScript (React)

Этот проект представляет собой библиотеку переиспользуемых React-компонентов и демонстрационное приложение, showcasing их использование. Архитектура проекта разделена на две основные части:

## Структура проекта

### `ui-library/`  
Библиотека переиспользуемых React-компонентов с собственной системой дизайна. Каждый компонент включает:
- TypeScript типизацию
- CSS-модули для стилизации
- Unit-тесты
- Документацию пропсов

### `frontend/`
Демонстрационное приложение с примерами использования компонентов из ui-library. Используется для:
- Демонстрации возможностей компонентов
- Тестирования в реальных условиях
- Разработки и отладки компонентов

## Компоненты библеотеки
### 1. Button 
- стиль,размеры и типы  кнопки
- отключение состояние кнопки
- содержимое кнопки
- обработчик клика

### 2. Photo
- основное изображение с fallback при ошибках
- постоянный текст вверху слева
- овальный элемент справа внизу
- анимированный текст при наведении



### Установка и запуск
1. Клонирование репозитория
Использовать команду: git clone < repository-url >
Использовать команду: cd project

2. Установка зависимостей и запуск UI Library
Использовать команду: cd ui-library
Использовать команду: npm install
Использовать команду:  npm run build - сборка библиотеки

3. Запуск демо-приложения
Использовать команду: cd ../frontend
Использовать команду: npm install
Использовать команду: npm run dev - разработка с вотчером
4. Открытие в браузере:
http://localhost:5173/
5. Проверка на налчие ошибок 
- npm run test - запуск тестов
- npm run lint - проверка кодстайла
