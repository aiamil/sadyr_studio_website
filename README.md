# sadyr_studio_website

Разработка сайта маркетингового агентства с использованием JavaScript (React)

Этот проект представляет собой библиотеку переиспользуемых React-компонентов и демонстрационное приложение, showcasing их использование. Архитектура проекта разделена на две основные части:

## Структура проекта

### `ui-library/`

Библиотека переиспользуемых React-компонентов с собственной системой дизайна. Каждый компонент включает:
- TypeScript типизацию
- CSS-модули для стилизации
- Unit-тесты
- Документацию пропсов

### `frontend/`
Демонстрационное приложение с примерами использования компонентов из ui-library. Используется для:
- Демонстрации возможностей компонентов
- Тестирования в реальных условиях
- Разработки и отладки компонентов

## Компоненты библиотеки
### 1. Button
Универсальный компонент кнопки с несколькими вариантами:
- Три размера: small, medium, large
- Два стиля: primary (основной) и secondary (второстепенный)
- Поддержка типов button и submit
- Состояние disabled с визуальной индикацией
### 2. Photo
Компонент фотографии с интерактивными элементами:
- Основное изображение с обработкой ошибок загрузки
- Постоянный текст вверху слева (заголовок и описание)
- Овал с текстом в правом нижнем углу
- Скрытый блок с дополнительной информацией при наведении

### 3. Banner
Компонент баннера с фоновым изображением и текстами:
- Настраиваемое фоновое изображение
- Три текстовых блока с позиционированием (left, center, right)
- Адаптивный дизайн

### 4. ProjectsGallery
Адаптивная галерея проектов с разными размерами:
- Три варианта размера элементов: small, medium, large
- Расположение элементов в двух колонках с определенной логикой размещения
- Каждый элемент содержит изображение с оверлеем и информационный блок
- Интерактивные элементы: клик по изображению или кнопке для перехода/действия

### 5. CaseProjectsGallery
Компонент для показа фотографий и галереи на страницах кейсов:
- Состоит из фотографии и имеет снизу текст и кнопку
- Оптимизирован для страниц кейсов (меньшие размеры, чем ProjectsGallery)
- Кнопки на страницах Case_1, Case_2, Case_3, Case_4 не ведут на соответствующие страницы,сделаны для показа как мог выглядеть сайт.

### 6. WorkProcess
Компонент для визуализации процесса работы или этапов:
- Двухколоночная структура: левая часть с заголовком и изображением, правая с шагами
- Нумерованные шаги с анимационными задержками для последовательного появления

### 7. Accordion
Интерактивный компонент для раскрывающихся блоков:
- По умолчанию только один элемент открыт (можно настроить множественное открытие)
- Плавная анимация раскрытия/скрытия контента
- Иконка плюс/минус с анимацией перехода
- Настраиваемые заголовок и элементы через пропсы

### 8. BenefitsGrid
Компонент сетки преимуществ:
- 9 карточек с текстами
- Кастомные фоны (цвет или изображение) для каждого элемента
- Опциональные границы и интерактивность (кликабельные элементы)
- Контролируемые отступы между элементами (small/medium/large)

### Установка и запуск
1. Клонирование репозитория
Использовать команду: git clone < repository-url >
Использовать команду: cd project

2. Установка зависимостей и запуск UI Library
Использовать команду: cd ui-library
Использовать команду: npm install
Использовать команду:  npm run build - сборка библиотеки

3. Запуск демо-приложения
Использовать команду: cd frontend
Использовать команду: npm install
Использовать команду: npm run dev - разработка с вотчером
4. Открытие в браузере:
http://localhost:5173/
5. Проверка на налчие ошибок 
- npm run test - запуск тестов
- npm run lint - проверка кодстайла
